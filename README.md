# Kamal Vinayagamoorthy — Portfolio

Apple-inspired dark portfolio website for GitHub Pages.

## Publish with GitHub Pages

1. Create a GitHub repository named `yourusername.github.io`.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
3. Put your PDF resume in `assets/Kamal-Vinayagamoorthy-Resume.pdf`.
4. In GitHub: Settings → Pages → Deploy from branch → `main` → `/root`.
5. Your site will be available at `https://yourusername.github.io/`.

## Before publishing

- Replace the resume PDF with the latest version if needed.
- Add your LinkedIn URL in `index.html` when ready.
- Add a professional profile photo only if you want one.
- Review every achievement and metric before public publishing.
